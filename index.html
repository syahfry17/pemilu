Integrasi Database Google Sheets

Hubungkan aplikasi ke Google Spreadsheet via Google Apps Script Web App

Status Saat Ini: Mode Demo Lokal

Data masih tersimpan di browser ini. Tempelkan URL Web App Google Apps Script di bawah ini agar seluruh tim bisa membaca dan menyimpan data secara terpusat di Google Sheet.

Belum punya URL-nya? Buka tab "2. Panduan & Kode Apps Script" di atas untuk menyalin kode backend siap pakai.

Langkah Pemasangan di Google Sheet (3 Menit):

  1. Buka sheets.new untuk membuat Google Spreadsheet baru (beri nama misal: Database Pemilu Kabupaten).
  2. Klik menu Extensions (Ekstensi) → Apps Script.
  3. Hapus semua kode bawaan di editor, lalu klik tombol "Salin Kode Apps Script" di bawah ini dan paste ke editor Apps Script.
  4. Klik ikon Save (Simpan), lalu klik tombol biru Deploy (Terapkan) → New deployment (Deployment baru).
  5. Pada ikon roda gigi (Select type), pilih Web app. Isi Execute as: Me, dan Who has access: Anyone (Siapa saja).
  6. Klik Deploy, izinkan akses (Authorize access), lalu salin Web app URL (akhiran /exec) ke Tab 1 di atas.
